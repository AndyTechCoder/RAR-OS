# Prompt 7A Pre-authorization Evidence

Status: M1.6 immutable input delivery; M2 transaction construction pending; execution unauthorized

ADR 0022 replaces the earlier mutable prepared/attested graph with a temporal DAG that has no commit self-reference. The committed `closure-input-lock-v4` binds only immutable external inputs, schema/grammar versions, algorithms, and policies. A future completed `preauth-transaction` run emits an external immutable `transaction-bundle-v1` and `transaction-graph-v1` exactly once for an exact checked-out source SHA. Distinct push and pull-request `ci-attestation-v3` leaves retain event/run/attempt/workflow identity while an `attestation-set-v1` proves both leaves name the same deterministic graph. Review certificate, owner authorization, and signed launch session are later temporal nodes and are neither committed nor fabricated by Prompt 7A construction.

M1 freezes schemas, typed Rust parsing, version refusal, transaction bounds, privilege separation, deterministic encoding, failure effects, and atomic-publication semantics. M1.5 removes every executable consumer and producer of the superseded pipeline. M1.6 adds only an untrusted immutable byte-delivery route. The networked producer receives no secrets, OIDC, environment authority or credentials; it cannot build source or emit transaction, certification, authority or session records. Its content-addressed canonical bundle is passed to a distinct networkless transaction process, which validates framing and inventory availability before the stable M2-incomplete refusal. The producer refuses APT redirects outright, verifies every effective acquisition origin from the recorded transfer state with an executable rejection path for foreign origins, and verifies the registry daemon has no mirror configured while registry blobs remain digest-pinned. The production entrypoint's refusal paths are repository-effect-free: its executable is built only inside an ephemeral non-repository boundary, and executable contract tests prove byte-identical repository state across usage, authority-environment, and malformed-bundle refusals. The bounded JSON parser enforces ADR 0022's frozen limits exactly — 1 MiB length, container depth 64, 4,096 object keys, 4,096 array items, and 64 KiB strings — with acceptance-at-limit and rejection-over-limit tests, and the pax timestamp grammar admits exactly one raw encoding: no leading-zero record lengths or seconds, no duplicate timestamp keys, and no trailing-zero fractions. Delivery never grants trust. The pinned base OCI image is delivered only as a canonical transport archive produced by a repository-owned bounded validator running inside the pinned networkless container: it parses the raw Docker export framing with strict member path, type, count, collision, and size bounds and exact root-owned `0755`/`0644` member metadata, accepts pax extended headers only as a parsed canonical timestamp grammar, re-hashes every content-addressed blob against its declared name, structurally parses `oci-layout`, `index.json`, the selected OCI manifest, the image config, the ordered layers, and Docker's legacy `manifest.json`, requires the exact digest-pull identity policy — a bare index descriptor carrying exactly `mediaType`, `digest`, and `size` with no annotations and no `platform` object, `RepoTags` exactly null, one exact `LayerSources` binding per uncompressed diff ID, and no tag-bearing `repositories` root — proves index→manifest→config→layer reachability, digest-verifies then excludes edge-free store metadata so the canonical archive equals the rooted graph exactly, and re-serializes the validated regular files with sorted names, the fixed source epoch, numeric root ownership, mode `0644`, and ustar framing. The canonical output is created through held directory descriptors, its digest is emitted by the validator and re-verified at assembly, and the producing host additionally binds the daemon-verified pinned registry digest reference and loaded image ID to the validated config digest. Raw export serialization is never bundled, so both acquisition slots and both CI event routes must produce byte-identical bundle digests; the observed exact-head base export graph has five ordered layers. Package copyright files are delivered inside one canonical `license-archive` member set, keeping the bundle at 50 objects; the delivery policy, envelope parser, and transaction planner share the single frozen 64-object bound from ADR 0022, a semantically valid 64-object envelope (up to 50 package rows plus the 14 required singletons) is an executable accepted conformance boundary, and the transaction boundary separately pins the approved 36-package closure.

The approved closure contains exactly 36 canonical package rows. Every row binds binary name/version/architecture/filename/size/hash/license hash and signed-snapshot source package name/version. Acquisition compares the complete observed manifest and every closure evidence field to the committed lock before any package byte is extracted or delivered. The strict derived-image OCI verifier described by ADR 0018 — canonical `repositories` tag binding, twice-built byte-identical archives, Buildx/config/loaded-image binding — is an M2–M5 obligation that does not exist yet; no derived image, profile, command, artifact, disk, host, graph, attestation, review, owner authorization, or session identity is current evidence. Current exact-head evidence covers only the delivered base export, whose validated rooted graph has five ordered layers, and the previously diagnosed exclusion of edge-free content-addressed store metadata now applies to that delivery as executable code.

Repository output ownership is specified in [preauth-output-ownership.md](preauth-output-ownership.md). M1.6 publishes only an untrusted input bundle; it creates no transaction output. M2 must implement descriptor-held private staging and atomic no-replace publication before any transaction bundle or graph can exist.

No profile, command, artifact, archive, disk, host, graph, attestation, review, owner authorization, or session digest is current evidence until M2–M5 regenerate it through the frozen DAG. Prior prepared records survive only as parser-rejection fixtures and are not production evidence.

# Prompt 7A Pre-authorization Evidence

Status: M1.6 immutable input delivery; M2 transaction construction pending; execution unauthorized

ADR 0022 replaces the earlier mutable prepared/attested graph with a temporal DAG that has no commit self-reference. The committed `closure-input-lock-v4` binds only immutable external inputs, schema/grammar versions, algorithms, and policies. A future completed `preauth-transaction` run emits an external immutable `transaction-bundle-v1` and `transaction-graph-v1` exactly once for an exact checked-out source SHA. Distinct push and pull-request `ci-attestation-v3` leaves retain event/run/attempt/workflow identity while an `attestation-set-v1` proves both leaves name the same deterministic graph. Review certificate, owner authorization, and signed launch session are later temporal nodes and are neither committed nor fabricated by Prompt 7A construction.

M1 freezes schemas, typed Rust parsing, version refusal, transaction bounds, privilege separation, deterministic encoding, failure effects, and atomic-publication semantics. M1.5 removes every executable consumer and producer of the superseded pipeline. M1.6 adds only an untrusted immutable byte-delivery route. The networked producer receives no secrets, OIDC, environment authority or credentials; it cannot build source or emit transaction, certification, authority or session records. Its content-addressed canonical bundle is passed to a distinct networkless transaction process, which validates framing and inventory availability before the stable M2-incomplete refusal. Delivery never grants trust. The pinned base OCI image is delivered only as a canonical transport archive produced by a repository-owned bounded validator running inside the pinned networkless container: it parses the raw Docker export framing with strict member path, type, count, collision, and size bounds (permitting pax extended headers only for discarded timestamp metadata), re-hashes every content-addressed blob against its declared name, structurally parses `oci-layout`, `index.json`, the selected OCI manifest, the image config, the ordered layers, and Docker's legacy `manifest.json`, proves index→manifest→config→layer reachability with uncompressed diff-ID equality and exact optional `LayerSources` binding, rejects any unexpected member, digest-verifies then excludes edge-free raw-store metadata blobs so the canonical archive equals the rooted graph exactly, and re-serializes the validated regular files with sorted names, the fixed source epoch, numeric root ownership, mode `0644`, and ustar framing. The producing host then binds the daemon-verified pinned registry digest reference and loaded image ID to the validated config digest before assembly. Raw export serialization is never bundled, so both acquisition slots and both CI event routes must produce byte-identical bundle digests. Package copyright files are delivered inside one canonical `license-archive` member set, keeping the bundle at 50 objects; the delivery policy, envelope parser, and transaction planner share the single frozen 64-object bound from ADR 0022.

The approved closure contains exactly 36 canonical package rows. Every row binds binary name/version/architecture/filename/size/hash/license hash and signed-snapshot source package name/version. Acquisition compares the complete observed manifest and every closure evidence field to the committed lock before extracting any package into the derived image. The strict OCI verifier bounds and checks the tar, Docker's required canonical `repositories` member, canonical OCI index bytes and exact two-annotation policy, manifest, config, layers, diff IDs, reported descriptor, and actually loaded image ID across two byte-identical builds. The repository index is one root-owned `0644` regular file of at most 512 bytes and must byte-exactly bind the sole `rar-preauth:<checked-out-head>` tag to the verified final layer; its bytes are covered by the canonical archive digest. The raw Docker export is validated before extraction and projected to the exact rooted graph. At the diagnosed closure, six inline content-addressed Docker-store blobs had no inbound edge and were excluded; the canonical archive contains only its four roots, sole config, six ordered layers, and unique OCI image manifest. A final archive containing any unreferenced valid-looking digest still fails closed. Diagnostics sort and cap normalized path/type/size/mode/ownership/digest/class/inbound facts and never print member content.

Repository output ownership is specified in [preauth-output-ownership.md](preauth-output-ownership.md). M1.6 publishes only an untrusted input bundle; it creates no transaction output. M2 must implement descriptor-held private staging and atomic no-replace publication before any transaction bundle or graph can exist.

No profile, command, artifact, archive, disk, host, graph, attestation, review, owner authorization, or session digest is current evidence until M2–M5 regenerate it through the frozen DAG. Prior prepared records survive only as parser-rejection fixtures and are not production evidence.

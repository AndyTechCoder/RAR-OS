# Signed runtime observation expectations

This independent host-only oracle is preparation for the certified cloud
scenario, not a VM launcher or an acceptance result. It does not import target
code, execute images, write files, create screenshots or authenticate publishers.

For one attempt on newly provisioned factory media it reconstructs every byte
of the fixed8MiB System image: factory in A, the exact attempted package in B,
zero sector padding and unused space, and exact two-sector selector records.
Rejection preserves factory selection; installation selects generation2 (or the
supplied strictly newer laboratory candidate); fallback selects factory while
preserving the committed high-water mark and the exact parent-record hash.
All reserved and unrelated bytes must match, not just selected fields or hashes.
These expected bytes must never be presented as actual retained media.

The separate Settings visual expectation renders factory, updated comfortable,
and updated compact scenes through the existing independent host renderer. It
does not read app source to determine pixels. Full actual captured PPM equality
will be required; expected frames are not screenshots and are not emitted.

Pure tests use explicitly synthetic unsigned package-shaped bytes and generated
expectations. They reject changed selector/slot/padding/reserved bytes, wrong
outcomes, truncated frames and impossible factory spacing. This demonstrates
checker behavior only. The eventual controller must independently bind actual
source/tool/boot/package provenance, authenticate retained Data, verify whole
VM/backend joins and System I/O durability, and correlate real input, captured
views and lifecycle behavior. No M4.2 completion or cloud execution is implied.
